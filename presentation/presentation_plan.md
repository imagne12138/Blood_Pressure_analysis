## Slide 2: 研究背景（~1min）

- **问题**: 无创连续血压监测的需求 (cuffless, PPG-based)
- **挑战**: PPG→BP 映射的不适定性（同一 PPG 可对应不同 BP）
- **现有方案**: 纯 PPG 端到端 / 手工特征 / 混合融合
- **本文定位**: 系统比较这三类方法，验证分头注意力和门控融合的有效性

---

## Slide 3: 数据预处理（~1min）

- **数据源**: MIMIC II（1967 人，每人 1–6 条 30s 记录）
- **预处理流程**:
  - Butterworth 带通滤波 (0.5–8 Hz PPG, 0.5–30 Hz ABP)
  - 峰值/谷值检测 → 分段（1024 点/段, overlap 50%）
  - 异常值剔除: SBP < 60 / > 250, DBP < 30 / > 160
- **数据集**: 最终 ~11000+ 有效段，5-fold 按人分层

## Slide 5: 门控融合机制（~1min）

放 `model_gated.drawio` 图。

- 特征先投影到 16D 低维空间
- context 经过 Linear(256→16) + sigmoid → 每个维度的开关
- 开关 × 投影特征 = 选择性注入
- 优点：context 能自己决定哪些特征有用

## Slide 6: 消融实验总览（~2min）

| 模型            | SBP MAE         | DBP MAE        | 关键差异      |
| :-------------- | :-------------- | :------------- | :------------ |
| Baseline        | 16.28           | 7.30           | 共享注意力    |
| Model 2         | 15.67           | 7.00           | 分头注意力 ✅ |
| MLP-26          | 21.05           | 9.05           | 仅手工特征    |
| MLP-169         | 16.25           | 7.86           | 169 维 + MLP  |
| FusionModel26   | **15.53** | **6.86** | concat 融合   |
| FusionModel-169 | 15.79           | 7.04           | 169 concat    |
| Gated-26        | 16.15           | 7.09           | 门控融合      |
| Gated-169       | 17.34           | 7.33           | 门控 + 169    |

**结论**:

- 分头注意力 vs 共享: **SBP −0.61, DBP −0.30**
- 门控不如 concat → 门控太保守，gate 接近 0 退化为纯 PPG
- 融合模型全面优于纯特征模型 → context 信息量大于手工特征

## Slide 7: 最优模型深度分析 — FusionModel26（~3min）

逐一展示分析图和对应的解读：

1. **逐折 Bar Plot**（5 折 SBP/DBP MAE + 误差条）→ 跨折稳定性
2. **Scatter Plot**（真值 vs 预测，分 fold 着色）→ 整体线性趋势
3. **Bland-Altman 图**（误差 vs 均值）→ bias, LoA, AAMI 标准
4. **Residual QQ 图** → 残差正态性（不对称 → BP 分布偏态）
5. **Attention 权重分布**（128 时间步的权重 profile）
6. **Centered Attention Scatter**（SBP vs DBP 权重，y≈−x 关系）
7. **JS Divergence** → 量化 SBP/DBP 注意力分布差异 (0.3–0.5)

**关键叙事**: SBP 和 DBP 关注不同时间区域（y≈−x），证明分头注意力不是冗余设计。JS divergence ~0.3–0.5 进一步确认为不同的分布模式。

## Slide 9: 设计结论（~1min）

1. **分头注意力有效** — SBP/DBP 各自关注 PPG 不同时间相位
2. **融合优于纯 PPG** — context + 特征 = 互补信息
3. **门控并不优于 concat** — 简单拼接在数据量足够时更稳定
4. **手工特征单独不够** — MLP 上限低，只能做 context 的补充角色

---

## Slide 10: 局限与 Future Work（~1.5min）

1. **数据分布偏态**

   - MIMIC II 的 BP 集中在正常范围 → 极端值预测差
   - → **个性化微调**（few-shot per subject）
2. **单模态信息有限**

   - PPG 心率与 BP 相关但不充分
   - → **引入 ECG + PPG 双模态**
   - → **BMI、Age 等人口学信息**（但 MIMIC II 缺少这些字段）
3. **CORAL 领域自适应尝试**

   - SBP 略差于最优模型（~+0.3），DBP 退化严重（~+1.5）
   - 原因：CORAL 强制对齐分布 → 破坏了 DBP 本就微弱的 PPG 映射
   - 启示：**先分类（按 BP 水平分层）后回归** 更合理
